# Courses and projects

Use this page as a link directory. Setup instructions and current results remain
in each repository.

## Lab courses and projects

| Resource | Responsibility |
| --- | --- |
| [CI: Mission Control](https://github.com/DyCo-AI/go1_gesture_tracking) | Gesture navigation using WebRTC on Go2. Go1 and G1 support are under development. |
| [Data-Driven Learning](https://github.com/DyCo-AI/data_driven_learning_course) | Graduate-level course offered by Dr. Umesh Vaidya, with assignment code and related resources for data-driven modeling and control. |

## Related repositories

| Repository | Focus |
| --- | --- |
| [Safe Control Density](https://github.com/sriram-2502/safe_control_density) | Density-function-based safe navigation methods implemented in Python. |
| [Go1 Density Social Navigation](https://github.com/sriram-2502/go1_density_social_nav) | Density-based safe and social navigation using a Unitree Go1, ZED 2i camera, and Jetson AGX. |
| [RK-MPC](https://github.com/sriram-2502/rk-mpc) | Residual Koopman model predictive control for quadruped locomotion in unstructured and off-road environments. |
| [XArm Density](https://github.com/sriram-2502/xarm-density) | Density-based whole-arm motion control and safety validation for the UF850 manipulator. |
| [KoopmanMPC Quadrotor](https://github.com/sriram-2502/KoopmanMPC_Quadrotor) | Koopman-operator-based model predictive control for a quadrotor. |
| [Deep Koopman AutoEncoder](https://github.com/sriram-2502/Deep_Koopman_AutoEncoder) | Neural Koopman autoencoder models for learning lifted representations of nonlinear dynamics. |
